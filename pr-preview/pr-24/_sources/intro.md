# EK125 Slides (Section C1, DePasquale)

This is a companion site to the main [EK125 course site](https://BU-EK125.github.io/EK125/intro.html), collecting interactive slide decks built with [marimo](https://marimo.io). Unlike the other EK125 sites, these aren't Jupyter notebooks -- they're live, editable, runnable Python apps that execute entirely in your browser (via WebAssembly), no installation or sign-in required.

Use the sidebar to pick a class. Each deck is embedded directly in the page below -- give it a moment to load (it's downloading a full Python runtime to your browser the first time), then navigate with the arrow keys or on-screen controls.
